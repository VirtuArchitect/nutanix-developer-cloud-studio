# v9.2.0 Infrastructure Tester Console

`v9.2.0-infrastructure-tester-console` makes the real-infrastructure tester journey visible from the Admin console instead of requiring operators to piece it together from scripts and separate panels.

## Added

- Admin Infrastructure tab for the tester workflow:
  - Connect Prism Element or Prism Central.
  - Browse read-only PE/PC inventory.
  - Record connection profiles and read-only gates.
  - Approve image, network, and cluster catalog candidates.
  - Create/preflight controlled AHV VM lifecycle runs.
  - Poll, power on, power off, and destroy lab runs.
  - Review audit and reconciliation evidence.
- Frontend API helpers for AHV controlled-provisioning `poll`, `power`, and `destroy`.
- One-time Prism Element/Prism Central connection tests now return sanitized read-only inventory previews from successful list calls.
- The Connect Infrastructure wizard can promote a successful validation into an approved read-only lab profile using safe endpoint references, credential references, and bounded UUID scope.
- Infrastructure-focused audit/reconciliation panel that filters Prism, AHV, inventory, lab-runtime, and controlled-provisioning events.

## Safety

- The public static demo remains simulated and cannot contact private infrastructure.
- Real AHV lifecycle still requires the hosted/on-prem API, Platform Admin role, `APP_ENV=lab`, private credentials, allowed UUID scope, and all AHV lab switches.
- Browser-entered Prism passwords are one-time connection-test inputs only and are not persisted, logged, documented, or exported.

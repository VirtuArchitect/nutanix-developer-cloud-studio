# v9.3.0 Inventory Scope Approval

## Summary

This release turns discovered Prism inventory into governed lab scope evidence. Platform Admins can approve or reject discovered clusters, networks/subnets, and images from the Admin Infrastructure workspace before any controlled AHV create flow is attempted.

## Added

- API-backed approve/reject route for Prism inventory scope records.
- Platform Admin-only RBAC enforcement for inventory scope decisions.
- Redacted audit events for approve/reject decisions.
- UI controls in Admin > Infrastructure > Image, subnet, and cluster approval.
- Browser mock fallback so the static demo can exercise the approval workflow.
- Smoke coverage for approving discovered scope from the Infrastructure tab.

## Safety Boundary

Approving inventory scope does not provision infrastructure. It records governance evidence only. Real AHV lifecycle remains lab-only, disabled by default, and requires private credentials, explicit lab switches, bounded UUID scope, controlled provisioning gates, and Platform Admin authorization.

## Tester Flow

1. Open Admin > Providers and import or discover Prism inventory.
2. Open Admin > Infrastructure.
3. Review discovered cluster, network/subnet, and image records.
4. Approve only the lab-safe records intended for controlled AHV testing.
5. Continue to controlled AHV VM create/preflight after the remaining lab gates are satisfied.

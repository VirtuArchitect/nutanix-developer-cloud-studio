# v9.7.0-pe-pc-validation-rings

`v9.7.0-pe-pc-validation-rings` adds a staged validation pack for authorized Prism Element and Prism Central testers.

## Highlights

- Adds `docs/pe-pc-validation-rings.md`, which separates PE/PC testing into local safety validation, connection testing, read-only inventory, scope approval, guardrails, controlled lifecycle, audit redaction, and resilience rings.
- Adds `validate:pe-pc-test-pack`, a metadata-only script that confirms the validation guide, required smoke scripts, and safety language are present.
- Updates README tester instructions with a safe PE/PC validation sequence before any opt-in real lifecycle smoke.

## Safety Boundary

- The validation-pack script makes no Prism calls.
- Real lifecycle remains lab-only, disabled by default, Platform Admin-gated, and dependent on private environment variables plus approved lab scope.
- Browser-entered Prism credentials remain one-time connection-test inputs and must not be persisted, logged, exported, or committed.

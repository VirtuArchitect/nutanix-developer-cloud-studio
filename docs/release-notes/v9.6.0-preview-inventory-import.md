# v9.6.0 Preview Inventory Import

## Summary

This release completes the real read-only connection flow from the browser into the inventory approval workflow. A Platform Admin can test Prism Element or Prism Central, review the sanitized inventory preview, and load that preview into the main inventory browser for approval and controlled AHV create selection.

## Added

- `POST /api/prism/inventory/preview-import` for sanitized connection-test preview imports.
- Connect Infrastructure wizard button to load successful read-only previews into the inventory browser.
- Preview import summaries with read-only scope, record counts, profile candidates, and blocked mutation operations.
- Server-side preview sanitization that keeps safe metadata only and resets records to `Discovered`.
- Audit events for preview imports without passwords, tokens, or Authorization headers.
- Unit coverage proving preview imports populate `/api/prism/inventory` and keep connection-test credentials out of inventory/audit state.

## Safety Boundary

Preview imports are evidence-only and read-only. They do not persist browser-entered passwords, do not store Authorization headers, and do not enable AHV mutation. Controlled create still requires approved scope, private lab environment variables, explicit lifecycle switches, and Platform Admin authorization.

## Tester Flow

1. Open Admin > Infrastructure > Connect infrastructure.
2. Enter Prism Element or Prism Central details.
3. Run Test read-only connection.
4. Review the sanitized inventory preview.
5. Click Load preview into inventory browser.
6. Approve discovered cluster, network/subnet, and image records.
7. Select approved scope in Controlled AHV VM lifecycle.

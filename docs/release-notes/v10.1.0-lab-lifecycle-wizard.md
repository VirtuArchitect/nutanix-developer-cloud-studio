# v10.1.0-lab-lifecycle-wizard

`v10.1.0-lab-lifecycle-wizard` combines the v10.0 and v10.1 goals: moving the AHV lab path from script-driven validation into a product-guided tester workflow.

## Highlights

- Added a Connect Infrastructure wizard that explains the private lab setup path from endpoint entry through read-only validation, candidate loading, and lab-runtime readiness.
- Added an AHV lifecycle wizard in the Admin console that shows scope approval, create/clone, power check, destroy, and reconciliation progress.
- Added Prism task-provider evidence so Platform Admins can see whether lifecycle tasks were submitted through Prism Central or Prism Element.
- Hardened polling semantics so create, power, and destroy actions only move to completed status after their Prism task reports success.
- Changed destroy reconciliation so a VM is considered destroyed only after the destroy task succeeds and read-only inventory no longer contains the VM.

## Validation

- `npm.cmd run test -- server/ahvLabRuntime.test.ts server/apiServer.test.ts src/services/cloudStudioApi.test.ts --reporter=verbose`
- `npm.cmd run build:all`

## Security Notes

- Real AHV lifecycle remains lab-only, disabled by default, and requires private environment variables plus explicit feature flags.
- Lifecycle routes remain Platform Admin-gated.
- The public GitHub Pages demo continues to use mock/simulated data only.
- Credential material is not persisted in docs, frontend state, audit events, or lifecycle records.

## Operational Boundary

This release does not enable production provisioning. It makes authorized lab testing understandable and operable from the product while retaining the existing guardrails around Prism Element and Prism Central access.

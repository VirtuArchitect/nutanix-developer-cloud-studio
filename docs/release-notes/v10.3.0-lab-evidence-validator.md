# v10.3.0 Lab Evidence Validator

`v10.3.0-lab-evidence-validator` combines the v10.2.0 and v10.3.0 goals: making the lab path easier to validate before execution and easier to package after execution.

## Highlights

- Added an API-backed AHV lab setup validator that checks runtime switches, private Prism configuration, read-only preflight evidence, approved inventory scope, controlled provisioning gate, lifecycle proof, and create authorization readiness.
- Added an Admin Infrastructure validator panel that explains blocked items and next actions for testers preparing a private Prism Element or Prism Central lab run.
- Added an API-backed redacted lab session evidence report for controlled AHV provisioning runs.
- Added an Admin Infrastructure evidence report panel with export and JSON download controls.
- Extended API/client/unit coverage and E2E smoke coverage for the validator and evidence report flow.

## Validation

- `npm.cmd run test -- server/apiServer.test.ts src/services/cloudStudioApi.test.ts --reporter=verbose`
- `npm.cmd run build`
- `npm.cmd run build:api`
- Full release checks are recorded in the release task before tagging.

## Security Notes

- Setup validation and evidence export remain Platform Admin-only.
- Evidence reports include lifecycle metadata and task references only.
- Prism passwords, tokens, Authorization headers, and endpoint query strings are excluded from reports and audit metadata.
- Public GitHub Pages remains a static simulated demo. Real AHV lifecycle remains lab-only, opt-in, and disabled by default.

## Operational Boundary

This release does not make NDC Studio a production provisioning platform. It strengthens the authorized lab workflow so testers can prove readiness before controlled AHV execution and export a redacted evidence pack after destroy and reconciliation.

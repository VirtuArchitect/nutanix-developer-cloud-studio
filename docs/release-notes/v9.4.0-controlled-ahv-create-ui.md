# v9.4.0 Controlled AHV Create UI

## Summary

This release connects approved Prism inventory scope to the controlled AHV create/preflight workflow. Testers can now approve cluster, network/subnet, and image records, select them in the AHV lifecycle panel, and record that approved scope on the controlled create run.

## Added

- Approved cluster, network/subnet, and image selectors in the Admin AHV lifecycle panel.
- Controlled AHV create/preflight request fields for selected inventory record IDs.
- Server-side validation that active AHV lab create requires approved Prism scope.
- Run evidence that records sanitized selected scope names, references, approver, and approval time.
- Browser mock fallback that enforces the same approved-scope evidence requirement.
- E2E smoke coverage for approving scope and using it in the controlled AHV preflight panel.

## Safety Boundary

The selected scope is not a credential store and does not expose Prism passwords, tokens, or Authorization headers. Real AHV mutation remains available only in an explicitly configured lab API deployment with private environment variables, bounded UUIDs, Platform Admin access, and all lifecycle gates satisfied.

## Tester Flow

1. Import or preview Prism inventory.
2. Approve the intended cluster, network/subnet, and image.
3. Open Controlled AHV VM lifecycle.
4. Select the approved scope records.
5. Run Create / preflight VM.
6. In lab mode, continue with poll, power, destroy, and reconciliation evidence.

# v9.5.0 Lifecycle Reconciliation

## Summary

This release makes the controlled AHV lifecycle workflow easier to test and audit. AHV runs now carry a lifecycle event ledger, and the Admin Infrastructure dashboard summarizes run activity, reconciliation status, and redacted audit events.

## Added

- Lifecycle events on AHV controlled provisioning runs:
  - Create submitted
  - Poll
  - Power submitted
  - Destroy submitted
  - Reconciled
  - Safe-mode notice
- Prism Central and Prism Element lab adapters append event evidence during lifecycle operations.
- Disabled and browser mock preflight paths emit non-mutating notice events.
- Admin AHV lifecycle panel renders the latest lifecycle event timeline.
- Admin Infrastructure audit and reconciliation dashboard summarizes active runs, reconciled runs, and recent lifecycle events.
- AHV lifecycle action audit metadata includes redacted lifecycle event evidence.

## Safety Boundary

Lifecycle evidence records operational metadata only. Prism credentials, Authorization headers, tokens, and passwords are not stored in run records, audit events, docs, or browser state. Real mutation remains lab-only and guarded by private environment variables, approved scope, controlled provisioning gates, and Platform Admin access.

## Tester Flow

1. Approve cluster, network/subnet, and image scope.
2. Select the approved scope in Controlled AHV VM lifecycle.
3. Create or preflight the VM.
4. Poll task status.
5. Power on/off where authorized.
6. Destroy the VM.
7. Confirm reconciliation evidence and redacted audit events.
